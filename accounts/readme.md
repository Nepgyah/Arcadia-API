# Accounts Docs

## Overview
This app manages all things related to accounts and profiles on the arcadia platform, handling both authentication and authorization

## Models
In order to incorporate a centralized account via D2X. The main *user* account for arcadia is simply a profile shell connected through a d2x_id field.

## API
Though Arcadia will be designed to utlized both graphql and rest endpoints, the accounts app will mainly be communicated through rest endpoints
