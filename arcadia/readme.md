# Arcadia Module Docs

## Overview
Container for misc and general use code. Also serving as a standard for building various parts of the Arcadia API.

### Module library
- **graphql** - Contains common types, responses and general permissions\
- **serializer** - Contains inhertiable serializers from django rest framework\
- **exceptions** - High level exceptions for Arcadia scenarios, inherited from drf exceptions\
- **mixins** - Standardize inhertitable models to build Arcadia data\
- **wrapper** - Common use wrappers for service and repository level methods\
- **util** - Misc functions
